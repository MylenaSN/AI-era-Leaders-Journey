# trilhas/

Pastas que o Journey publica em `http://game.patronloop.com/{slug}/play.html`.

A AFOL **não** mora aqui. Fonte: o pai (`domain/game/play.html` + `game/`). O publisher espelha isso para:

- `/play.html` — MVP/POC do Loop · Mylena de Souza Nascimento
- `/trilha-operations-leaders/play.html` — slot isolado da mesma formação

Outro mentor: crie `trilha-{audiencia}-leaders/` **aqui**, com `play.html` + `game/` próprios. O Loop Game só mexe nessa pasta.
