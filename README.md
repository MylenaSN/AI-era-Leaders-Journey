# AI-era Leaders Journey

Runtime estático da jornada gamificada (16 semanas). Repo privado + GitHub Pages.

## Abrir no celular ou desktop

1. Ative **GitHub Pages**: Settings → Pages → Branch `main` → folder `/ (root)` → Save.
2. Aguarde ~1 minuto.
3. Abra a URL do Pages (ex.: `https://mylenasn.github.io/AI-era-Leaders-Journey/`).
4. Senha: **human loop**

Progresso salvo no `localStorage` do navegador.

## Local

```bash
python -m http.server 8765
```

Abra `http://127.0.0.1:8765/` → senha **human loop**.
